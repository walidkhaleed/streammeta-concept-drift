# Routing baseline decisions

Prepared before V5 outcome inspection. This is an implementation decision record, not a rewrite of Related Work. A source link/code claim is not evidence that its code has passed V5's environment or delayed-feedback tests.

| Candidate / paper | Year | Code availability | Selection unit / input state | Label timing assumptions | Stream compatibility | Fair reproduction feasibility / V5 decision |
| --- | --- | --- | --- | --- | --- | --- |
| Recent verified-error selector (transparent V5 counterfactual, no attributed paper) | 2026 implementation | `src/streammeta/models.py` | HAT versus ARF per instance; exactly the same four verified-history features/window as Meta; lower recent hard error, ties HAT | Only released labels; original historical probabilities; both experts updated at release | Native canonical engine, including delay | Implemented. Directly tests whether fitting the router improves on this specified simple selector. It is not advertised as a published state-of-the-art method. |
| HAT, ARF, SRP | Established River implementations | Installed, pinned River package; constructor signatures archived per run | Standalone classifier/ensemble per instance; same online scaling and learner seed design | Test then train on released labels | Native online interface | Implemented as the requested expert/ensemble comparators. Five ensemble members fixed before outcomes. No retuning to disadvantage competitors. |
| Cavalheiro et al., *Dynamically Selected Ensemble for Data Stream Classification* (DDCS) | 2021 | Authors explicitly link [dcspaperCode](https://github.com/dcspaper/dcspaperCode) in the [paper](https://jpbarddal.github.io/assets/pdf/2021_IJCNN_ddcs.pdf) | Dynamic classifier/ensemble selection using query competence and evolving stream ensembles | Stream supervised-feedback protocol; a delayed-label adaptation would need separate validation | Designed for streams | Relevant candidate. Not implemented in this campaign: faithfully aligning the original ensemble, competence mechanism, probabilities and delayed-label semantics needs a separate reproduction. No weakened two-expert surrogate is called DDCS. |
| Cruz et al., *META-DES: A Dynamic Ensemble Selection Framework using Meta-Learning* | Journal 2015; linked preprint deposited 2018 | [Paper](https://arxiv.org/abs/1810.01270); [DESlib](https://github.com/scikit-learn-contrib/DESlib) provides a maintained implementation family including META-DES | Classifier competence/ensemble selection using multiple meta-features and a dynamic-selection set | Labeled meta-training/selection data; not the same sequential delayed-label contract by default | Batch dynamic selection; requires an explicit online adaptation | Candidate only. Replacing its training/selection protocol with V5 rolling history would change the method and require new leakage controls. Do not claim a reproduction without that work. |

Literature-backed learned selection remains an unresolved breadth issue. The required transparent counterfactual is included; optional competitors are deferred for methodological reasons, not because preliminary results favored V5.
