# Additional source findings and implementation log

Before V5 scientific outcomes:

1. The old `normalize_binary_label` maps boolean/string labels in order first observed. Verified in E2E cell 8 and repeated worker helpers (inspection dump lines 136–141, 490–495, 948–953). V5 fixes boolean/numeric 0/1 semantics and rejects undeclared labels. This can change positive-class interpretation and the resulting learning trajectory. It is not evidence of old future-label leakage, and old/new metric differences cannot be attributed to one isolated change.
2. The initial installed SHAP transitive stack (`numba 0.67.0`, `llvmlite 0.49.0`) crashed at native-library load with SIGBUS in this execution environment. No scientific run had started. `numba 0.61.2` and `llvmlite 0.44.0` passed import and actual tree-SHAP/cross-fit snapshot tests with NumPy 2.2.6 and SHAP 0.52.0. The compatible versions are pinned, with all other third-party versions in `requirements-lock.txt`. This is an observed environment compatibility finding, not a claim about general upstream reliability.
3. Matplotlib 3.10.0 emits 14 Pyparsing deprecation warnings during test import under the frozen dependency set. They do not skip tests or invalidate outputs; the full warning text remains in the test report.
4. The managed execution environment exposes a procfs mounted from a different PID namespace. A nested test process has a different `os.getpid()` from `/proc/self`; `psutil.Process()` therefore failed rather than identifying the current process reliably. The staged test gate caught this before scientific runs. Linux RSS now reads the kernel-resolved `/proc/self/statm` resident-page count, and affinity uses `sched_getaffinity(0)`. Both namespace and procfs PIDs and the RSS source are archived. A nested-process regression test checks this path. No fallback substitutes another process's memory or fabricated samples.
5. A post-run integrity check found some completed Parquet files had become shorter and no longer matched the size/SHA-256 in their run artifact manifests. A workspace synchronization process was present; external synchronization is a plausible cause, not conclusively established. The affected output campaign and its gates were quarantined. The implementation now stages Parquet writes and publishes complete run directories atomically; the new campaign runs in an unsynchronized temporary directory, then is archived as a closed, checksummed artifact. All scientific phases are rerun under the new source hash; old summary numbers are not accepted in place of raw evidence. The integrity incident and rejected files remain recorded for review.
6. The first full XAI validation exposed a permutation-design bug: observed folds were class-balanced, while unrestricted block-label permutations changed fold class counts. Training-class-prior shifts then depressed the out-of-fold null distribution (representative null mean approximately 0.38 versus chance 0.5). Four of ten stationary controls produced p<=0.05. This is a failed scientific calibration check, not evidence of feature shift. The correction conditions each block permutation on the observed fold class counts by shuffling whole blocks within folds. A structural regression test enforces equal observed/null fold balances and block integrity; every null block assignment is archived. All scientific phases are rerun under the corrected source. No predictive hyperparameter is selected using these outcomes; the prescribed primary metric, streams and paired design remain unchanged. The rejected calibration output is retained for independent review.

Manuscript-only audit issues remain queued in `issue_reconciliation.md`; no manuscript source was edited. Old AUC tables are imported only by reporting for explicitly non-equivalent historical comparison, never by the learner, plan, metric or acceptance-gate code.
