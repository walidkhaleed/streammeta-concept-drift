# V5 design frozen before outcome inspection

Primary predictive metric: **exact empirical prequential ROC AUC**, computed by scikit-learn from every saved pre-update class-1 probability and true label. Diagnostic online metric: River ROC AUC with **101 explicit thresholds**, chosen for a transparent 0.01 probability grid while retaining streaming efficiency. It is never substituted for exact AUC. All models receive the same fixed label encoding and original stream order.

Methods: HAT; ARF (5 models); SRP (5 models); bounded XGBoost Meta; recent verified hard-error selector. All use the same online StandardScaler/expert definitions, except that standalone baselines contain only their own learner. The recent-error selector uses the exact same four verified-history features/window, chooses ARF only when its recent hard error is strictly lower, ties HAT, and falls back to ARF before a complete window. It continues training both experts. No fabricated published competitor is added.

Router: buffer 1000, refit after 250 newly eligible observations subject to two-class availability; fresh 10-tree depth-3 XGBoost, learning rate 0.1, binary logistic/logloss, CPU hist, one job. Expert hard label >=0.5; manager chooses ARF iff q>0.5. Current hidden labels never enter the prediction interface. State means retain direct O(w) semantics; any future running-sum optimization needs separate validation.

Seeds are independent named values: data=42, drift wrapper=142, model=242, router=342, XAI=442, resource-run=542 for the principal configuration. A SHA-256 domain-separated post-data seed is derived from the data seed and explicitly recorded; pre-data seed equals data seed. Post/pre generators are not identically seeded. Hyperplane uses data seed directly and always magnitude 0.001, 10 features, 3 drifting features.

Materialize each stream once as canonical sorted-key finite JSON records in gzip; hash the uncompressed canonical observation bytes (not gzip metadata or Parquet serialization). Config/manifest records native generator parameters, River version, real-source hashes and label mapping. All arms read the same immutable materialization; actual consumed hashes are rechecked in every run. Cache IDs exclude window, delay, method, learner seeds, and experiment labels.

Principal horizon: Elec2 45,312; Phishing 1,250; four synthetic streams 10,000. Matched window and delay Agrawal arms use 50/100/500 and 0/100/500 respectively. The principal, window-100 and delay-zero controls must agree in every predictive trace value, exact/approx AUC, routing and fit count, not merely stream hash. Timings/run IDs are intentionally not equality targets.

Repetitions: **10** fixed in advance, configurable to 20 or more. This is a modest repeatability study, not a power calculation or a stopping rule based on significance. Synthetic data robustness varies data and independently named wrapper seeds per repetition while holding model/router seeds fixed. Thus it estimates variation across the specified randomized stream-generation design, not learner-seed variance. For each real native-order stream, data/order remain fixed and model/router seeds vary. Per-seed results and design labels are retained; the two sources of uncertainty are not pooled as one estimand. Extra factorial learner/data experiments are available through explicit configs, not silently mixed into this study.

Within a repetition all methods and all ablation arms share the identical materialized stream and all non-manipulated seeds. Summaries: mean, median, sample SD, IQR, and per-repetition values. Paired Meta-minus-recent-error exact-AUC effect is predeclared within each dataset/design; use a two-sided Student-t interval across repetition differences only when n>=2 and label its assumptions and small-n limits. Single-run CI fields remain null. No transaction-level confidence interval or universal performance conclusion.

Across-dataset analysis: primary-seed exact AUC for all five methods on the six datasets; lower rank means higher exact AUC. Report Friedman asymptotic p as limited at six blocks and descriptive ranks. Nemenyi only if this predeclared omnibus p<0.05; otherwise absent. Multi-seed means/ranks are separate exploratory summaries, not additional independent dataset blocks. Report practical differences regardless of significance; never infer equivalence.

XAI: external ADWIN delta=.002 sees verified routed errors. Order on release: detector -> eligible explanation snapshot -> manager/state/expert learning. Both event/error sample and current verification step are logged. Raw windows end at the event processing step and are labeled older/newer retrospective; delayed mode may include currently observed unlabeled x but no future x. Tier 1 is current-router attribution over historical valid meta-states. Tier 2 uses blocked cross-fitting, out-of-fold temporal discrimination and attribution, block-preserving permutation null calibration, and fold stability. Output remains descriptive temporal-window attribution; significance does not establish a causal drift driver. Separate predefined null, label-rule, covariate and mixed synthetic controls check behavior; no control is presented as a new real dataset or published baseline. No automatic attribution/localization claim is restored.

Resource: high-resolution monotonic clocks, fresh processes, fixed native thread counts, full raw timings/RSS. Initialization and first 1000 warm-up observations are reported separately from subsequent observations without resetting the learned model. A short 2000-step diagnostic and full-horizon mode are supported; full profiles cross configured transition centers. Three repeats with resource-run seed controlling run order only; scientific model/data seeds stay fixed. Resource repetitions estimate runtime variation, not predictive uncertainty. Run resource jobs serially on the measured host after predictive jobs finish. Record affinity, cgroup quota, NUMA/CPU/RAM, load, GC, versions and threadpools. Maximum sampled RSS uses bytes and MiB; recording/acquisition/posthoc metrics and artifacts have explicit separate boundaries. No microcontroller, energy, real-time, universal-latency or total-memory claim follows.

Only tests/smoke precede controlled validation; smoke results are ineligible for paper tables. Scientific runs require a source-bound passing test gate and successful matched-control gate. Any subsequent scientific-source edit invalidates those gates and requires retesting; results retain their original source hash and are never silently overwritten.
